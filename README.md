# EL FARES Store — إعدادات Supabase جاهزة

تم وضع رابط مشروع Supabase ومفتاح Publishable الذي زودني به المستخدم داخل `supabase-config.js`.

## حالة إعداد قاعدة البيانات
- تم إنشاء الجداول `admins` و`products` و`orders` من خلال SQL Editor.
- تم إنشاء سياسات RLS بعد إصلاح تكرار اسم إحدى السياسات.
- تم إضافة حساب المدير الحالي إلى جدول `admins`.
- **الخطوة المتبقية في Supabase:** افتح SQL Editor > New query، والصق محتوى `supabase-permissions.sql` ثم Run مرة واحدة. هذا يضيف أذونات API الأساسية فقط ولا يحذف بياناتك أو يعيد إنشاء الجداول.

## النشر على GitHub Pages
ارفع محتويات المجلد `el_fares_store` إلى نفس المستودع الذي ينشر الموقع، مع الحفاظ على الملفات والمجلد `assets`.
تأكد أن `index.html` و`admin.html` و`store.js` و`admin.js` و`supabase-config.js` في جذر الموقع المنشور نفسه.
بعد انتهاء النشر افتح:
- المتجر: رابط موقعك المعتاد.
- لوحة الإدارة: أضف `/admin.html` إلى نهاية رابط الموقع.

## تسجيل الدخول
سجّل الدخول في لوحة الإدارة ببريد وكلمة مرور مستخدم Supabase الذي أضفته إلى جدول `admins`.
لا تنشئ مستخدم مدير جديداً ما دام حسابك الحالي موجوداً ومضافاً بالفعل.

## الأمان
- `Publishable key` الموجود في `supabase-config.js` مخصص للاستخدام في المتصفح.
- لا تضع أبداً `Secret key` أو `service_role` أو كلمة مرور قاعدة البيانات في ملفات الموقع أو GitHub.
- حماية المنتجات والطلبات تعتمد على تسجيل دخول المدير وسياسات RLS.
- لا تشارك بيانات دخول المدير مع أحد.

## ملاحظات
- لا تعِد تشغيل ملف `supabase-setup.sql`؛ الجداول والسياسات أُنشئت بالفعل في مشروعك.
- إذا كان الموقع لا يزال يعرض المنتجات التجريبية، تحقق من تشغيل `supabase-permissions.sql` ومن رفع كل الملفات إلى جذر الموقع المنشور.
- الخطة المجانية لها حدود استخدام وقد تتغير؛ لا يوجد اشتراك شهري مطلوب ضمن حدود الخطة المجانية الحالية.
